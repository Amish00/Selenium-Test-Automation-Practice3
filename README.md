# SauceDemo UI Automation Testing

This repository contains an automated testing suite for [SauceDemo (Swag Labs)](https://www.saucedemo.com/), a standard practice application for UI automation. The framework is built using Java and Selenium WebDriver 4, utilizing TestNG for test execution and assertions.

The scripts are designed with visual observation in mind, utilizing intentional execution pauses to allow QA engineers and learners to watch the automation interact with the DOM in real-time.

## Tech Stack

* **Language:** Java (JDK 11+)
* **Web Automation:** Selenium WebDriver 4
* **Testing Framework:** TestNG
* **Build Tool:** Maven
